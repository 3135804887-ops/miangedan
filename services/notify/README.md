## 职责

- **区域化通道契约**：每个数据区独立邮件通道配置（`Config.Validate` fail-closed：
  区域/环境合法、必含 email 通道、发件人形如邮箱）。
- **区域路由与隔离**：`Router` 按 `data_region` 路由；某区通道故障/未配置不影响他区，
  未配置区发送直接拒绝（TASK-007 验收"单区通道故障不影响他区"）。
- **消息约束**：消息必须携带幂等键（写操作幂等，AGENTS.md 第 3 节）；模板变量禁止携带
  正文/令牌/媒体（PRIVACY-DATA-MAP：通知模板变量无正文）。

## 红线

1. 跨区发送默认拒绝（ADR-0005）；消息区域必须与通道区域一致。
2. 通知模板变量不得携带简历正文、完整回答、令牌、原始媒体。
3. 真实供应商调用必须经适配层接入（AD 决策 4），本包只承载契约与路由。
