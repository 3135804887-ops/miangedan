| 字段 | 内容 |

## 1. 目的

把 PRD 的阶段退出条件转化为可逐项打勾、可留证的发布守门清单。**任一 P0 风险未关闭、任一零容忍项触发，禁止发布。**

## 2. 范围

Phase 0 组件验证、Phase 1 内部 Alpha、Phase 2 封闭 Beta、Phase 3 三数据区生产验证、Phase 4 GA 放量，以及全阶段通用检查（回滚、状态页、客服、退款、隐私、事故响应）。

## 3. 非目标

- 不设定日历日期（PRD 以质量门槛为准）；不替代 ACCETANCE-MATRIX 的用例执行细节。
- 签字不代表免除后续持续治理义务（每月评分复测、每季度恢复演练等）。

## 4. 通用守门（每个阶段都必须满足）

- [ ] P0 风险全部关闭（见第 5 节逐项证据）。
- [ ] 零容忍项为 0：严重数据泄露、越权访问、重复扣费、评分证据丢失。
- [ ] 验收矩阵（ACCEPTANCE-MATRIX）适用用例 100% 通过，无未豁免失败。
- [ ] 回滚方案就绪：提示词/模型/量表/工作流/前端可独立回滚；**活跃正式会话继续使用冻结版本，新会话回滚至稳定版本**。
- [ ] 中英文状态页可发布；错误预算未耗尽（耗尽则暂停非必要发布）。
- [ ] 客服知识库与工单通道就绪；退款与故障自动返还通道经演练。
- [ ] 隐私请求通道（查询/导出/更正/删除/撤回）可用并显示真实进度。
- [ ] 事故响应：SEV-1~4 分级、通报模板、值班表、复盘流程就绪。
- [ ] 监控按数据区/语言/输入模式/供应商/岗位族/版本切分；日志扫描无简历正文/完整回答/令牌/原始媒体。

## 6. Phase 0：组件与供应商验证

- [ ] 中英文 ASR、LLM、TTS、数字人、WebRTC 均使用合成简历、合成 JD 与授权测试角色完成验证。
- [ ] 对比维度留档：延迟、口型、打断、弱网、数据区、授权链、单位成本、可替换性。
- [ ] 每项核心能力至少一个主方案 + 一个替代方案通过验证。
- [ ] **退出条件**：所有候选组件达到 PRD 实时、安全、授权与区域要求；不合格供应商不进入真实用户链路。
- [x] OD-01（最终主备供应商）决策记录归档（2026-08-04，签字见 docs/decisions/OD-01-signoff.md，ADR-0006）。

## 7. Phase 1：完整内部 Alpha

- [ ] 个人端、机构端、运营后台、支付、隐私、删除与全部 1–5 轮闭环可用。
- [ ] 真实实时数字人链路（无静态头像/预录/人工替代）。
- [ ] 评分回归、安全红队、无障碍基础测试、供应商与数据库故障演练全部通过。
- [ ] **退出条件**：全部 P0 功能完成；关键流程通过率 100%；无开放 P0 风险或严重缺陷。

## 8. Phase 2：封闭 Beta

- [ ] 中文用户 ≥1,000、英文用户 ≥1,000；中国/欧盟/国际区均有真实测试用户。
- [ ] 覆盖 ≥20 类岗位族与不同级别；覆盖应届、在职跳槽、转岗与需要合理便利的用户。
- [ ] 累计 ≥10,000 个有效正式轮次；评分样本经独立专家盲评校准。
- [ ] **退出条件**：评分硬门槛、SLO、安全、隐私、无障碍与支付补偿要求全部达标。
- [ ] Beta 身份、风险与退款政策在产品中清楚展示。
- [ ] OD-02（正式定价）在真实付费前决策归档。

## 9. Phase 3：三数据区生产验证

- [ ] 中国、欧盟、国际区分别完成 2 倍预计峰值容量压测。
- [ ] 区域内容灾演练：单 AZ 60s 接管；区域级 RTO ≤30min；证据 RPO=0。
- [ ] 供应商切换、跨区域账户边界、支付、删除、机构隔离测试通过。
- [ ] 单一区域故障不扩散；备用系统不违法跨境（无静默跨区复制证据）。
- [ ] **退出条件**：三个数据区域全部达到硬门槛。
- [ ] OD-03（各区域法律实施）、OD-05（峰值容量基线）决策归档。

## 10. Phase 4：Global GA

- [ ] 放量阶梯 1% → 5% → 20% → 50% → 100%，每步覆盖完整监测周期。
- [ ] SLO、评分、退款、安全或报告质量任一异常 → 停止放量并回滚（新会话）。
- [ ] 中英文状态页、客服、隐私请求与事故通知渠道同步上线。
- [ ] 持续治理排程生效：每月评分稳定性与公平性复测；每季度恢复/供应商切换/删除演练；每半年岗位覆盖与来源质量更新；重大变更重走离线→影子→灰度→回滚验证。

## 12. 关键规则

1. P0 未关闭不发布；零容忍项触发即停止一切放量。
2. 活跃正式会话永远使用冻结版本；回滚只影响新会话。
3. 阶段差异只是验证对象与流量，不允许以删除关键能力形成低配版本。
4. 检查单每项必须留证（报告链接/工单/演练记录），口头确认无效。

## 13. 异常处理

- 发布后发现 P0 级问题：立即停止放量 → 新会话回滚 → SEV 流程 → 受影响用户救济（故障返还/重试/退款）→ 复盘并更新本清单。
- 门槛指标临界（如一致率 84.9%）：不得四舍五入放行；升级 AI/评分负责人决策并记录。
- 区域验证不齐：不得单区抢跑 GA；可先维持该区域 Beta 身份。

## 14. 验证方式

1. 每阶段结束由 QA 汇总本清单留证并归档版本。
2. 清单本身随 PRD 阶段定义变更同步更新并记录 CHANGELOG。
3. 每季度复核第 5 节证据是否仍然有效（持续治理）。
