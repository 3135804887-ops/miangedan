# 设计系统（DESIGN-SYSTEM）

| 字段 | 内容 |
|---|---|
| 文档编号 | DESIGN-002 |
| 版本 | 0.1.0（工程占位规范，待 Design Lead 评审） |
| 追踪 | PRD-001 "Design & UX Requirements"（UX Principles、Responsive Platform Rules、Localization） |
| 一致性锚点 | `docs/design/SCREEN-SPEC.md`、`docs/design/ACCESSIBILITY.md` |

## 1. 目的

为前端实现提供统一的初始设计原则、语义色板、字体层级、间距刻度、组件状态与中英文排版规则，使多个开发代理/工程师产出的界面保持一致。

## 2. 范围

- 设计原则、语义颜色、字体层级、间距、组件状态、中英文排版。
- 本文件为**工程占位规范**：颜色与字体数值为可运行的默认占位，品牌视觉（logo、品牌色、插画、图标体系）**未确定**，由 Design Lead 评审后以新版本替换。

## 3. 非目标

- 不生成最终品牌视觉、logo、营销插画或动效设计。
- 不绑定具体组件库实现（仅定义语义与状态约定）。
- 不改变 PRD 的任何 UX 规则；冲突时以 PRD 为准。

## 4. 设计原则（继承 PRD UX Principles）

| 原则 | 工程含义 |
|---|---|
| 真实互动优先 | 数字人视频区在房间布局中为主视觉；不得用静态头像/PPT 占位冒充 |
| 降低开始成本 | 分步表单、随时保留草稿、每步可回退 |
| 正式感但不压迫 | 评分、计费、故障提示用严谨语气；品牌文案可轻松；不夸大 AI 能力 |
| 状态明确 | 计时/网络/录制/输入模式/下一步常显；状态变化有文字说明 |
| 不泄题 | 计划与轮次间隙只展示范围与标准 |
| 可恢复 | 错误提示五要素（影响/数据保留/可重试/是否计费/是否影响评分） |
| 包容优先 | 输入方式与合理便利不作负面区分展示（见 ACCESSIBILITY） |
| 不使用暗黑模式 | 订阅、续费、录制、机构分享、模型训练授权各自独立、清楚、可撤回；无诱导性默认勾选、无确认羞辱文案 |

## 5. 语义颜色（占位色板）

> 占位声明：以下色值为工程占位（基于中性蓝灰体系），**品牌视觉未定，待 Design Lead 评审后整体替换**；语义映射关系（而非具体色值）是本文件的稳定契约。所有语义状态不得仅靠颜色传达（必须同时有图标或文字，见 ACCESSIBILITY）。

| 语义令牌 | 占位值 | 用途 |
|---|---|---|
| `color.primary` | `#2B5CE6` | 主操作、链接、品牌强调 |
| `color.success` | `#1F9D66` | 通过态（PASS）、完成 |
| `color.warning` | `#B7791F` | 弱项、待处理、降级提示 |
| `color.danger` | `#C53030` | 未通过态（FAIL）、破坏性操作（删除） |
| `color.info` | `#2B6CB0` | 评估未完成（EVALUATION_INCOMPLETE）、中性提示 |
| `color.neutral.900` | `#1A202C` | 主文本 |
| `color.neutral.600` | `#4A5568` | 次级文本 |
| `color.neutral.100` | `#EDF2F7` | 分隔/背景 |
| `color.surface` | `#FFFFFF` | 卡片表面 |
| `color.focus` | `#805AD5` | 键盘焦点环（focus-visible，必须可见） |

三态语义区分（通过/未通过/评估未完成）：success / danger / info，**各自必须搭配不同图标与文字标签**（如 ✓ 通过、✕ 未通过、⏸ 评估未完成），禁止仅用颜色区分。

## 6. 字体层级

| 令牌 | 字号/行高（桌面） | 用途 |
|---|---|---|
| `font.display` | 32/40 | 落地页主标题 |
| `font.h1` | 28/36 | 页面标题 |
| `font.h2` | 22/30 | 区块标题 |
| `font.h3` | 18/26 | 卡片标题 |
| `font.body` | 16/26 | 正文（中文行高加大保证可读性） |
| `font.caption` | 13/20 | 辅助说明、状态标签 |

字族栈：

```css
--font-zh: "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
--font-en: "Inter", "Segoe UI", "Helvetica Neue", Arial, sans-serif;
--font-mono: "JetBrains Mono", "SFMono-Regular", Consolas, monospace; /* 代码编辑器、秒数与账单数字 */
```

## 7. 间距与布局

- 间距刻度：4px 基线（`space.1`=4 … `space.2`=8, `space.3`=12, `space.4`=16, `space.6`=24, `space.8`=32, `space.12`=48）。
- 页面最大内容宽度 1200px；房间页全宽利用。
- 断点（占位，对齐响应式规则）：`desktop ≥1024px`（完整功能）、`tablet 768–1023px`（完整流程，触控优化）、`mobile <768px`（资产/报告/语音文字面试；复杂代码白板引导桌面）。

## 8. 组件状态规范

所有交互组件必须实现以下状态（缺一不允许合入）：

| 状态 | 要求 |
|---|---|
| default | 满足对比度（正文 ≥4.5:1，大文本 ≥3:1） |
| hover | 仅桌面指针设备；不作为唯一信息通道 |
| active | 按下反馈 |
| disabled | 降透明度 + 不可聚焦 + 说明原因（如"该轮量表未就绪"） |
| loading | 骨架/旋转指示 + 可访问的忙碌标记（aria-busy） |
| error | 错误图标 + 文字（五要素），不只变红 |
| focus-visible | 清晰可见焦点环（`color.focus`，≥2px），键盘全程可达 |

## 9. 中英文排版规则

1. UI 语言与面试语言独立（用户可在 SCR-14 分别设置）；所有文案键入 i18n 资源，错误、字幕、支付、隐私、无障碍名称与报告解释均须翻译。
2. 中文正文行高 ≥1.6；中英文混排时数字与英文使用 `--font-en` 回退。
3. 标点：中文文案用全角标点；英文文案用半角；混排句子以主语言为准。
4. 日期、时间、货币、税费、数字按地区本地化（如 `2026-08-01` / `Aug 1, 2026`；`¥39.00` / `$6.99`），使用 ICU MessageFormat 或同等能力。
5. 双语并存元素（品牌名"面个蛋 MianGeDan"）顺序固定：中文在前英文在后。

## 10. 关键规则

1. 语义令牌是稳定契约，色值是占位变量；换肤只允许改色值，不允许改语义映射。
2. 任何状态不可只用颜色表达；focus-visible 不可移除。
3. 品牌视觉（logo/品牌色/插画）属未决事项：Owner = Design Lead，所需证据 = 品牌评审稿与商标检索（关联 OD-04），门槛 = 公开品牌发布前；此前一律使用本占位规范。
4. 不实现"暗黑模式诱导"类组件模式（确认羞辱、预勾选、隐藏退订）。

## 11. 异常处理

- 字体加载失败：回退系统字族栈，布局不得塌陷（预留字体度量 fallback）。
- 高对比模式/强制颜色模式（Windows HC）：语义边界用边框与图标兜底，不依赖背景色。
- 未知语言回退：`en-US` 为最终回退；缺失翻译键在 CI 报错，不允许页面显示原始键名。

## 12. 验证方式

1. 设计令牌（颜色/字号/间距）以机器可读形式（如 CSS variables/JSON tokens）入库，CI 校验对比度（AA）。
2. 组件状态清单（第 8 节）在 Storybook 或等价物中逐组件截图回归。
3. 中英文关键页面排版走查（SCR-01、03、06、08、10、11）双语言截图评审。
4. 品牌视觉替换时仅允许变更色值/字体值，语义映射 diff 必须为空（CI 检查）。
