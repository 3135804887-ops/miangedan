## 1. 目的

定义面个蛋全部页面的清单、状态、主要操作与异常路径，使前端实现、测试用例与验收矩阵对"每个页面在什么状态下展示什么、允许什么操作"有一致理解。

## 2. 范围

- 求职者端（游客/登录）、机构端、运营后台三类的全部页面。
- 每页的状态矩阵：空、加载、失败（含可重试动作）、权限不足、恢复路径。
- 桌面优先响应式规则在各页面的适用差异（Desktop 完整 / Tablet 完整 / Mobile Web 受限）。

## 3. 非目标

- 不定义视觉风格、组件库与最终 UI 布局（见 DESIGN-SYSTEM；PRD 线框图仅作功能键、信息与状态对齐参考）。
- 不定义 API 字段（见 `docs/api/openapi.yaml`）与实时事件载荷（见 `docs/api/realtime-events.md`）。
- 不绑定 PRD 截图中的 UI 样式；本文的文本线框同样只作功能参考。

## 4. 全局页面规则

1. **状态即数据**：页面展示的项目/轮次状态必须与 `INTERVIEW-STATE-MACHINE.md` 的状态枚举一致（DRAFT…COMPLETED），禁止页面层自创状态名。
2. **用户可见错误五要素**：任何错误提示必须说明 ①影响、②数据是否保留、③可重试动作、④是否计费、⑤是否影响评分（UX 原则"可恢复"）。
3. **不泄题**：计划页与轮次间隙只展示范围与标准，不展示正式问题；后续轮次开始前不展示完整标准答案。
4. **不压迫**：品牌语言可轻松，评分、计费与故障提示必须严谨；不使用暗黑模式诱导（订阅、续费、录制、机构分享、模型训练各自独立、清楚、可撤回）。
5. **录制与计时状态常显**：用户始终知道当前轮次、输入模式、网络、录制状态、是否计时与下一步。
6. **随时保留草稿**：上传、粘贴、解析、校对、生成计划分步完成，中断后可从最后有效状态继续。

## 6. 求职者端页面

### SCR-01 落地页与样例演示

- **主要状态**：默认介绍；样例演示（使用合成样例数据的非个人化演示）。
- **主要操作**：浏览介绍、查看样例演示、进入登录。
- **空状态**：无（纯内容页）。
- **加载/失败**：演示资源加载失败 → 显示重试按钮与影响说明（不影响任何个人数据，因为游客无个人数据）。
- **权限**：游客可用；尝试上传个人材料 → 跳转 SCR-02 登录，成功后返回原操作，不丢失允许暂存的非敏感输入。
- **恢复**：刷新后回到介绍默认态。
- **关键规则**：未满 16 岁用户仅可使用本页的无登录、无上传样例演示。

### SCR-02 登录/注册

- **主要状态**：选择登录方式；邮箱验证码输入；第三方授权跳转中；注册协议确认（服务条款、隐私政策、数据处理说明；录制/机构共享/模型训练另行授权，不在注册捆绑）。
- **主要操作**：邮箱验证码登录、Google/Apple/微信登录、发送/重发验证码（有效期、频率限制与风险验证）。
- **空状态**：无账户 → 引导注册流程（与登录同页切换）。
- **失败**：验证码错误/过期（说明剩余尝试次数与重发冷却）；**第三方登录故障 → 提供邮箱替代路径**（US-05 规则 9）。
- **权限**：可访问登录页本身；年龄声明在此收集（正式个性化服务最低 16 岁；16 岁至当地成年年龄需监护人验证流程）。
- **恢复**：登录成功后返回登录前操作上下文。

### SCR-03 工作台

- **主要状态**：项目列表（卡片含岗位/轮次/状态/下一动作）；筛选生效中；无项目。
- **主要操作**：新建面试、继续面试、下一轮、报告、练习、正式重试、复制项目、下载、更多（重命名/删除）；筛选：公司/岗位/日期/语言/状态。
- **空状态**：无项目 → 引导"新建面试"；筛选无结果 → 清除筛选入口。
- **加载**：骨架屏；**失败**：列表加载失败 → 重试按钮 + 影响说明（数据保留在账户中，不影响评分与额度）。
- **权限**：登录用户；仅本人项目。
- **恢复**：筛选条件保留在 URL，刷新可恢复。
- **关键规则**：项目状态徽标使用状态机枚举（如"当前轮未通过"对应 ROUND_FAILED），并配文字说明下一可用动作。

### SCR-04 创建面试项目

- **主要状态**：双栏输入（简历上传 / JD 粘贴）；文件处理中；文件被拒。
- **主要操作**：上传 PDF/DOC/DOCX（≤10MB）、删除/替换文件、粘贴完整 JD、触发解析、保存草稿。
- **空状态**：初始引导文案（样例材料可一键填充体验，标记为样例）。
- **失败**：文件损坏/加密/超限/伪装/检测不安全 → **拒绝并给出具体原因，且不丢失已填写的 JD**（US-01 场景 4）；网络失败 → 保留原始输入可重试。
- **权限**：登录用户；未登录操作被引导至 SCR-02。
- **恢复**：草稿自动保留；离开再进入恢复到最后编辑状态。

### SCR-05 解析校对页

- **主要状态**：解析中（进度与可等待提示）；待校对（结构化预览）；解析失败。
- **主要操作**：逐字段编辑（新增/修改/删除）、查看低置信度字段（高亮）、查看"未纳入面试的敏感字段"类别说明、确认材料、处理缺失影响弹窗。
- **缺失影响弹窗**：只有 JD / 只有简历 / 两者都缺失 → 说明对应降级模式（通用岗位面试 / AI 推导岗位画像并标记 / 通用面试）及影响；**只有用户明确同意才继续**（同意写入 ConsentGrant）。
- **失败**：解析服务中断 → 保留原始输入，可重试失败步骤或进入手动编辑（US-01 场景 5）。
- **权限**：材料所有人才可见；敏感字段（电话、邮箱、证件、地址、照片、性别、婚育）仅以"已排除类别"展示，不进入面试上下文。
- **恢复**：确认前离开 → 回到 MATERIAL_REVIEW 状态继续。
- **关键规则**：只有用户确认后才能生成计划（materials.confirmed）。

### SCR-06 面试计划页

- **主要状态**：计划生成中（分模块进度，失败模块单独重试）；待确认；已确认（只读快照）。
- **主要操作**：查看公开流程参考（来源/日期/官方或经验/可信度，非官方经验清楚标识）；轮次增删（1–5）、拖动重排、编辑角色/重点/难度（基础/标准/挑战）/时长（10–60 分钟）/风格/数字人与声音（固定授权角色库）；启停岗位工具；配置便利设置；恢复 AI 推荐；确认计划并进行会前检查。
- **空状态**：生成失败 → 保留成功部分并只重试失败模块。
- **失败**：某轮缺少问题覆盖方案或量表 → 该轮标记"未就绪"，**阻止确认进入**（US-02 场景 4）。
- **权限**：项目所有人；**用户不可修改**统一评分算法、60 分门槛、解锁逻辑、交接规则，不可提前查看正式问题与答案（界面上这些区域为只读说明）。
- **恢复**：确认前均可返回编辑；确认（plan.confirmed）后计划冻结并展示冻结说明。
- **报价联动**：确认页展示完整报价（轮次/总时长/重试权益/税费/有效期，见 SCR-15）。

### SCR-07 会前检查页

- **主要状态**：检查中；全部通过；某项失败。
- **主要操作**：摄像头/麦克风检测（可关闭继续）、网络质量检测、音频播放检测、数字人建连测试、确认便利设置（**冻结确认**）、查看本轮额度预留。
- **失败**：设备被占用/无权限 → 具体原因与替代输入建议（文字）；网络过差 → 就近节点建议与弱网说明；数字人建连失败 → 自动重试与客服入口（NFR-007：95% ≤8s，超时进入故障流程）。
- **权限**：仅项目所有人且单活动设备检查通过。
- **恢复**：检查项可单项重试；额度不足 → 阻止开始并提供购买（**不得**在面试开始后提示）。

### SCR-08 实时面试房间（功能布局）

功能分区（文本线框仅作功能参考）：

```text
┌──────────────────────────────────────────────────────────┐
│ 面个蛋实时面试 · {轮次名}   计时中/已暂停 | 网络 | 字幕开关 | 退出 │
├──────────────────────────────────────┬───────────────────┤
│ 数字面试官问题与实时字幕             │ 数字面试官视频流   │
│ （问题固定显示，可回看）              │ （始终开启）       │
│ 候选人转写（可修订，窗口内）          ├───────────────────┤
│ 动态追问                             │ 候选人摄像头       │
│                                      │ （可关闭）         │
│ [岗位工具区：代码/白板/案例/作品集]   │ 轮次进度/输入模式  │
├──────────────────────────────────────┴───────────────────┤
│ [麦克风] [摄像头] [停止数字人] [文字回答........] [提交]  │
└──────────────────────────────────────────────────────────┘
```

- **主要状态**：数字人建连中；进行中（计时中）；系统暂停（不计时）；重连中；文字降级中；回合推进。
- **主要操作**：语音作答、文字作答与提交、摄像头/麦克风开关、停止数字人（打断）、修订本轮转写（下一主问题前）、使用已配置岗位工具、查看字幕、退出（需确认）。
- **关键规则**：
  - 数字面试官视频流与音频**始终开启**；候选人摄像头/麦克风可关，不扣分。
  - 修订窗口提示明确：进入下一主问题后本轮转写冻结，评分使用修订文本，原始转写仅诊断保留。
  - 正式面试**不提供手动暂停**；退出需确认并明确提示"将标记为评估未完成"。
  - 未实际播放的数字人内容不写入记录；打断后数字人立即停止并切换聆听。
  - 未配置的辅助工具不出现在工具区（正式房间不临时加载）。
- **失败与恢复**：全部故障路径由 SCR-09 覆盖层承载；页面刷新/崩溃 → 3 分钟重连窗口，恢复到最后已确认回合。
- **权限**：仅当前活动设备可交互；第二设备进入被阻止并提示安全转移。

### SCR-09 暂停/重连/降级弹窗（SCR-08 覆盖层）

- **变体**：
  1. **系统故障暂停**：说明"系统故障已暂停计时，正在自动恢复；此段时间不计费、不影响评分"。
  2. **重连窗口**：3 分钟倒计时；说明"刷新/断网后可在倒计时内恢复到最后已确认回合，不扣时间、不判失败"；倒计时耗尽 → 标记评估未完成并给出重试入口。
  3. **数字人持续故障降级询问**："数字人音视频暂时无法恢复。是否改为文字面试继续？"——同意 → 文字面试继续（自故障点起不再消耗数字人额度；口语项标记未评估）；**拒绝 → 结束并标记评估未完成（不是失败），系统责任全额返还本轮预留额度**。
  4. **令牌重认证**："登录状态需要重新确认，计时已暂停，不会扣时间也不会判失败。"
- **权限/恢复**：所有弹窗操作幂等；网络抖动重复触发不重复弹窗、不重复扣减。

### SCR-10 轮次结果页

- **通过态**（ROUND_PASSED）：首先展示"**恭喜你通过本轮面试，已进入下一轮**"；展示总分、60 分线、关键维度通过情况、简短优势与注意点、流程进度、下一轮角色/重点/难度/时长；操作：立即进入下一轮 / 稍后继续。
- **未通过态**（ROUND_FAILED）：阻断下一轮；生成从第一轮到当前轮的累计纪要、证据与训练入口；操作：复盘练习 / 正式重试 / 查看报告 / 结束（生成部分报告）。
- **评估未完成态**（EVALUATION_INCOMPLETE）：明确说明"这不是失败"：原因（证据不足/系统故障/用户结束）、已保留内容、可重试入口；系统责任时展示额度已返还。
- **加载/失败**：评分中（预计 ≤60s，NFR-013）；评分服务故障 → 评估未完成说明 + 恢复后自动重算。
- **关键规则**：不展示可能泄露后续轮次考点的完整标准答案；复核入口在报告页（每次正式尝试一次）。

### SCR-11 完整报告页

- **模块**：状态与总分、各轮轨迹（含交接影响、能力锁定与分数变化）、岗位匹配度（必备/加分分列；无 JD 不展示百分比）、六维雷达图+**文字/表格等价版本**、逐题证据（问题/回答摘要/追问/分数/证据/做得好/缺失/矛盾/建议结构）、语音或文字沟通分析（标注输入模式及证据限制）、工具表现、优势与风险、优先训练计划、原始记录与删除入口。
- **主要操作**：复盘练习、正式重试、申请复核（每次正式尝试一次，展示复核前后结果与原因）、下载（导出必带"模拟训练结果，不代表真实企业录用结论"标记）、删除。
- **部分报告**（report_kind=partial）：有未完成轮次或模块失败 → 展示可用模块并标注缺失模块可单独重试（FR-026），不丢失评分证据。
- **空/失败**：报告生成中（P95 ≤120s，NFR-014）；单模块失败仅该模块显示重试。
- **权限**：仅项目所有人；机构访问另走授权（SCR-16 只见被授权范围）。

### SCR-12 练习页

- **主要状态**：练习进行中（可暂停）；练习结束。
- **主要操作**：原题/变体练习、查看提示/框架/示例、获取逐步反馈、结束练习。
- **关键规则**：**页面固定标识"练习不改变正式分数与解锁状态"**；练习不产生正式证据；练习内容不进入报告分数。
- **失败**：练习生成失败 → 重试；不影响任何正式记录。

### SCR-13 资产与历史页

- **主要状态**：简历库 / 岗位库 / 面试记录 / 训练进度 四个分区。
- **主要操作**：简历解析记录查看、编辑（产生新版本）、替换、删除；JD 编辑与版本；项目筛选与跨设备继续；训练薄弱点与正式重试轨迹。
- **并发设备**：正式面试在另一设备活动时显示"活动中"，进入被阻止并可经确认安全转移（US-05 场景 3）。
- **删除**：删除活动项目 → 明确说明将终止面试；删除进度真实反映数据库/对象存储/第三方处理进度。
- **空/失败**：各分区独立空态与重试。

### SCR-14 账户与隐私页

- **分区**：登录身份（多身份绑定/解绑，绑定需分别验证，冲突时不合并并提供人工支持路径）；界面语言与面试语言（独立设置）；授权中心（六类独立授权：核心服务必要处理、保存原始音视频、机构共享、非必要产品分析、模型训练或研究、营销通知——各自可撤回，撤回即时生效）；数据导出；删除账户。
- **删除账户**：重新验证后确认；展示真实进度（级联删除或不可逆匿名化；法定财务记录保留但解除内容关联）。
- **失败**：导出/删除任务失败 → 真实进度与重试；不伪造完成状态。

### SCR-15 购买与额度页

- **主要状态**：报价展示；支付流程；额度流水；订阅管理。
- **主要操作**：查看完整报价（轮次/总时长/正式重试/有效期/税费）；选择免费额度/单项目包/Pro/加油包；支付方式；**自动续费单独勾选**（扣款前提醒）；查看逐笔账单（项目/轮次/开始时间/使用秒数/返还原因/余额）；发票或收据；取消续费；退款或故障申诉。
- **失败**：支付成功未到账 → 订单显示"处理中"（禁止重复扣款）；支付失败 → 保留计划可重新支付；重复扣款 → 自动识别退回并通知。
- **关键规则**：不在面试中弹出续费/广告/余额不足；数据删除、隐私控制、证据解释、无障碍与故障恢复不收费；付费不改变评分标准。

## 7. 机构端页面组（SCR-16）

| 页面 | 主要内容与规则 |
|---|---|
| 机构任务列表 | 任务/截止时间/额度/成员概览 |
| 任务配置 | 岗位或岗位类别、材料要求、轮次、角色、时长、难度、语言、工具、截止时间、练习次数、机构额度；**不可配置** 60 分线、统一评分算法、保护属性规则、证据标准、跨轮解锁、正式复核（这些项不在界面上出现） |
| 完成情况 | 默认仅见：任务是否接受、未开始、进行中、已完成或退出、完成时间、系统故障、机构额度消耗；未授权时显示"已完成但未共享结果"，**不能显示失败** |
| 成员与邀请 | 邀请链接/机构邮箱/批量名单/SSO/SCIM；加入前向用户展示机构名称、可见数据、训练期限与退出影响 |
| 聚合趋势 | 岗位类别/能力维度/完成率/提升趋势；**细分群体 <10 人不展示**；无个人排行榜、排名、候选人搜索 |
| 权限与审计 | 角色（所有者/管理员/指导老师/隐私审计/财务/求职者）权限矩阵；用户可查看哪位机构人员何时访问了哪些数据 |
| 授权结果视图 | 仅展示用户针对具体任务授权的范围与有效期（如"仅雷达图 30 天"）；到期自动失效 |

异常：用户退出机构 → 机构访问立即失效，界面即时移除其数据入口；机构停用 → 成员令牌与共享链接立即失效。

## 8. 运营后台页面组（SCR-17）

| 页面 | 主要内容与规则 |
|---|---|
| 区域监控 | 区域在线房间、排队、容量、各供应商延迟与错误、SLO/错误预算；**默认只有匿名会话编号与技术指标** |
| 供应商与模型 | 路由/熔断/注册表（按区域/语言/能力）；变更含版本、说明、测试、审批、回滚；未完成离线-影子-灰度禁止全量发布 |
| 版本治理 | 提示词/量表/工作流/前端灰度与回滚；活跃正式面试固定开始版本 |
| 来源与内容安全 | 来源可信度/失效/下架/版权投诉；禁止配置绕过网站协议、登录、验证码或反爬 |
| 客服工单 | 默认只看账户状态、订单、额度、故障代码与用户主动提交材料；逐字稿需用户针对会话授权；媒体访问需用户申请+双人审批 |
| 财务与补偿 | 故障返还、大额退款双人审批、重复扣款处理 |
| 审计日志 | 追加式、管理员不可删除；破窗访问记录与事后复核 |

**全局禁止**：后台任何页面不存在编辑个人分数或解锁状态的控件；尝试通过 API 提交同类操作被拒绝并记录审计事件。

## 9. 状态矩阵（每页强制覆盖）

| 状态 | 通用要求 |
|---|---|
| 空 | 说明为什么为空 + 下一步引导；不得展示误导性占位数据 |
| 加载 | 骨架或进度；长时间加载给出预期时长（对齐 NFR 指标） |
| 失败 | 五要素错误提示（影响/数据是否保留/可重试动作/是否计费/是否影响评分）+ 重试按钮 |
| 权限不足 | 说明所需权限与获取路径（登录、授权、购买），不暴露他人数据存在性 |
| 恢复 | 刷新/重进后可从最后有效状态继续；正式面试恢复到最后已确认回合 |

## 10. 关键规则（红线复述）

1. 数字面试官始终实时音视频；候选人摄像头/麦克风可关；正式面试无手动暂停。
2. 通过祝贺文案固定首屏展示："恭喜你通过本轮面试，已进入下一轮"。
3. 评估未完成 ≠ 失败，界面文案必须明确区分。
4. 练习页固定"不改分"标识；报告导出必带训练用途标记。
5. 机构默认最小可见；后台默认脱敏；无改分控件。
6. 所有授权（订阅续费、录制、机构共享、模型训练）独立、清楚、可撤回，不使用暗黑模式。

## 11. 异常处理

| 异常 | 页面行为 |
|---|---|
| 任一 API 失败 | 五要素错误 + 重试；表单输入保留 |
| 媒体面故障 | SCR-09 覆盖层；页面主状态不丢失（控制面/媒体面分离） |
| 支付状态不明 | 订单"处理中"，禁止重复发起扣款 |
| 报告模块局部失败 | 可用模块正常展示，失败模块单独重试 |
| 第二设备进入 | 阻止提示 + 安全转移确认 |

## 12. 验证方式

1. 每页状态矩阵（第 9 节五行）在组件测试与端到端测试中逐页验证。
2. 关键文案（祝贺语、评估未完成说明、练习不改分标识、导出标记）有快照测试。
3. 权限路径（未登录、未授权、机构默认视图、后台脱敏）有端到端用例，映射 `docs/testing/ACCEPTANCE-MATRIX.md`。
4. 响应式断点（桌面/平板/移动 Web）按第 5 节平台差异逐页走查。
