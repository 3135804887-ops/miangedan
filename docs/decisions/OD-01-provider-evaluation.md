## 3. 评估方法与门槛（引用 Phase 0 方案）

- 评分口径：每类能力 100 分制，六维权重：实时性 30 / 质量 25 / 数据区与合规 15 / 授权与品牌安全 10 / 故障与可替换性 10 / 单位成本 10。
- 准入门槛（任一不满足即淘汰）：
  - 支持在用户所属数据区内处理（或提供区域化部署/端点）；中国区内容不默认出境；
  - 可签 DPA，承诺不留存用户内容用于模型训练；
  - 数字人候选必须提供固定授权角色库与完整肖像/声音授权链；不支持每场生成新脸、不做未授权克隆；
  - 提供沙箱/试用环境与可核算的单价模型；
  - 安全自评：传输加密、密钥管理、SOC 2/ISO 27001 或等效证明。
- 红线（一票否决）：数据默认出境、拒绝 DPA 零保留、授权链不完整、无法满足打断 P95 ≤ 500ms（数字人/ASR 链路合计）、无法提供固定角色库。
- 切换约束：故障演练验证熔断与切换，切换不得跨数据区。

## 4. 桌面预筛结论（待实测修订）

以下为 2026-08-03 桌面调研结果。评分仅用于缩小实测名单，实测后按 Phase 0 六维权重重新打分并回填。

### 4.1 WebRTC/SFU

- 候选：声网 Agora、腾讯云 TRTC、LiveKit Cloud（可自托管）、100ms。
- cn 区主/备建议：Agora（主）/ TRTC（备）。
  - Agora：国内节点成熟、弱网抗丢包能力强、按分钟计费；授权与合规材料齐全。
  - TRTC：腾讯生态内集成便利、与腾讯云数字人/ASR 联动成本低。
- eu/intl 区主/备建议：LiveKit Cloud（主）/ 100ms（备）。
  - LiveKit：提供 EU 区域部署、可自托管，自托管可满足数据驻留审计需求；区域固定，实测需确认目标区域可用性。
  - 100ms：区域覆盖好、按参与者分钟计费，单价量级约 $0.004/参与者分钟。
- 预筛关注点：建连成功率和时延指标（95% ≤ 8s、99% ≤ 15s）、弱网降级行为、录制与旁路能力、单价模型透明度。

### 4.2 ASR

- 候选：阿里云实时语音识别、讯飞、Deepgram（EU endpoint 已 GA、可自托管）、Azure Speech、OpenAI Realtime/Whisper。
- cn 区主/备建议：阿里云（主）/ 讯飞（备）。
  - 阿里云：实时识别按小时计费（量级约 ¥10/小时），中文与方言覆盖好、国内合规明确。
  - 讯飞：中文/方言资源深厚，作为备选可复用其 TTS 生态。
- eu/intl 区主/备建议：Deepgram（主）/ Azure Speech（备）。
  - Deepgram：EU 端点 GA、支持自托管、零保留配置；英文质量与延迟指标优秀。
  - Azure Speech：区域矩阵完整、与 Azure OpenAI 同栈，合规材料齐全。
- 预筛关注点：中英文及口音集字准率门槛（由 AI 负责人随校准基线确定）、最终文本时延 P95 ≤ 1s、方言覆盖（cn 区）。

### 4.3 TTS

- 候选：火山引擎豆包大模型语音合成、讯飞、ElevenLabs（EU data residency + Zero Retention）、Azure TTS。
- cn 区主/备建议：火山豆包（主）/ 讯飞（备）。
  - 豆包：大模型 TTS 自然度高、国内合规、与火山 LLM 生态联动。
  - 讯飞：音色库与中文表现稳定，授权链清晰。
- eu/intl 区主/备建议：ElevenLabs（主）/ Azure TTS（备）。
  - ElevenLabs：EU 数据驻留与零保留配置明确，多语种自然度高。
  - Azure TTS：企业合规成熟、区域矩阵完整。
- 预筛关注点：MOS 自然度盲评、音色授权范围（商用用途）、口型同步时延（与数字人链路合计 ≤ 200ms）、长文本稳定性。

### 4.4 LLM

- 候选：DeepSeek、通义千问 Qwen、讯飞星火、Azure OpenAI、Claude、Gemini。
- cn 区主/备建议：DeepSeek（主）/ Qwen（备）。
  - DeepSeek：单价显著低、中文质量强；**仅限 cn 区使用，eu/intl 属红线**。
  - Qwen：阿里生态、合规与部署方式灵活。
- eu/intl 区主/备建议：Azure OpenAI（主）/ Claude（备）。
  - Azure OpenAI：支持 Sweden/Switzerland 等区域部署、区域模型矩阵明确、DPA 与安全材料齐全。
  - Claude：多语种推理质量强，作为可替换备选。
- 预筛关注点：追问相关性、内容安全、评分链路确定性（温度与采样参数）、数据驻留配置、单位 Token 成本模型。

### 4.5 实时数字人

- 候选：腾讯云智能数智人、硅基智能、HeyGen、Synthesia。
- cn 区主/备建议：腾讯云智能数智人（主）/ 硅基智能（备）。
  - 腾讯云：基础形象库授权体系明确、与 TRTC 同栈联动成本低。
  - 硅基智能：国内 B2B SaaS 成熟，按月授权（量级约 ¥3K ~ 50K/月），需逐角色核验授权链。
- eu/intl 区主/备建议：HeyGen（主）/ Synthesia（备）。
  - HeyGen：商用角色库与授权条款清晰、API 完善。
  - Synthesia：企业级合规与固定角色库支持。
- 红线核验：固定授权角色库 + 完整肖像/声音授权链；禁止"每场生成新脸"与未授权克隆（含竞品演示中常见的任意克隆能力，不作为候选）。
- 预筛关注点：口型/音频偏差 ≤ 200ms、打断 P95 ≤ 500ms、长会话（60 分钟）稳定性、授权按角色还是按席位计费。

## 5. 成本估算（量级，待实测核价）

- cn 区全链路（SFU + ASR + TTS + LLM + 数字人月费摊薄）：量级约 **¥0.1 ~ 0.3/分钟/面试**（1 对 1 场景，30 分钟标准面试）。
  - ASR 约 ¥0.02/分钟量级、TTS 约 ¥0.02 ~ 0.05/分钟、SFU 约 ¥0.02 ~ 0.06/参与者分钟、LLM 按输入/输出 Token 折算约 ¥0.01 ~ 0.05/分钟、数字人按角色/月费摊薄。
- eu/intl 区全链路：量级约 **$0.1 ~ 0.25/分钟/面试**。
  - SFU 约 $0.004 ~ 0.024/参与者分钟、ASR 约 $0.017/分钟（OpenAI Whisper/Realtime 量级，Deepgram 按量定价）、TTS 约 $0.02 ~ 0.05/分钟、LLM 约 $0.005 ~ 0.03/分钟、数字人月费摊薄。
- 说明：以上为桌面量级估算，未含重试/失败调用与带宽成本；实测阶段以各供应商可核算单价模型回填，按 Phase 0 单位成本维度重新打分。

## 6. 待沙箱实测清单（窗口 2 前置输入）

- 数字人音视频建连：95% ≤ 8s、99% ≤ 15s（合成对话 ×200 次/供应商/区域，冷启动计时）。
- 用户发言结束 → 数字人开始回复：P50 ≤ 1.5s、P95 ≤ 3s、P99 ≤ 5s（全链路：ASR + LLM + TTS + Avatar）。
- 打断 → 停止发声：P95 ≤ 500ms（语音打断 + 停止按钮 ×100 次）。
- ASR 最终文本时延：P95 ≤ 1s；中英文及口音集字准率达标（≥30 样本/口音集）。
- 口型与音频偏差 ≤ 200ms（录制样本对齐分析）。
- 默认视频规格 ≥ 720p/24fps；弱网（3 Mbps / 512 kbps / 256 kbps + 30% 丢包）下降级行为观察。
- 60 分钟长会话稳定性：无内存泄漏、无连接退化（合成脚本长跑 ×10）。
- 故障演练：断网/限流/超时/熔断切换（closed/open/half_open）、活跃会话状态恢复；切换不跨区。
- 合规与授权核验：数据区处理证据、DPA/零保留配置、数字人固定角色库与授权链证明。

## 8. 风险与缓解

- 数字人授权链不完整（P0 风险，肖像/深度伪造）：任何候选未提供完整授权链即否决；OD-03（法律实施方案）联动核验。
- DeepSeek 仅限 cn 区：eu/intl 路由禁止进入 DeepSeek，配置层强制区域隔离。
- LiveKit Cloud 区域固定：实测前确认目标区域可用性；若不可满足则以自托管或 100ms 为主。
- 供应商单价模型不透明：无法核算成本则单位成本维度计 0 分，并在决策记录标注。
- 实测数据与供应商承诺严重不符：以实测为准并记录；两候选总分接近（差 < 5 分）时以红线项与故障演练结果为决胜项。
- 评测期间供应商服务降级：记录为故障样本，不因此延长评测窗口。
