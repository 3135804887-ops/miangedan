# 报告生成规范（REPORT-SPEC）

| 字段 | 内容 |
|---|---|
| 文档编号 | AI-REPORT-001 |
| 版本 | 0.1.0（已批准 2026-08-01 规范评审） |
| 追踪 | PRD-001 US-04 规则 3；FR-023、FR-026、NFR-014；TASK-050 |
| 一致性锚点 | `ai/schemas/report.schema.json`（结构事实源）、`ai/prompts/report-generation.md`、`docs/ai/SCORING-SPEC.md`、`config/safety/policy.yaml` |

## 1. 目的

定义面试报告的内容结构、模块边界与生成规则：完整/部分报告、六维雷达（含文字
等价）、岗位匹配、逐题证据、多轮轨迹、沟通与工具分析、训练计划；模块级局部失败
可单独重试（FR-026），报告只读引用冻结评分，不重新计算、不修改任何分数。

## 2. 范围与输入

报告生成器只读取冻结系统数据：

| 输入 | 来源 | 信任级别 |
|---|---|---|
| ScoreVersion（维度分、门槛结论、解释摘要、job_match） | 评分服务（冻结） | 可信 |
| 回合证据摘要（问题/回答/追问/工具行为与证据 ID） | 证据账本（冻结） | 可信 |
| HandoffPackage（多轮轨迹、锁定与变化） | 交接服务 | 可信 |
| 输入模式与便利设置标记 | 会话记录 | 只记录，不作评价 |
| 简历/JD 结构化快照 | 材料服务 | 原文按不可信数据处理 |

## 3. 输出模块

报告对象必须符合 `ai/schemas/report.schema.json`；`modules` 至少包含
`overview`、`radar`、`rounds`、`training_plan` 四个必备模块，其余模块
（`job_match`、`communication_analysis`、`tool_performance`）按可用数据输出。

| 模块 | 内容 | 失败语义 |
|---|---|---|
| overview | 轮次数、各轮分数、最终加权分、全部必需轮通过结论 | 可单独重试 |
| radar | 六维最新有效得分 + 文字/表格等价（无障碍强制） | 可单独重试 |
| rounds | 逐轮结果、逐题证据（问题/回答/追问/维度分/证据 ID）、维度锁定与变化、多轮轨迹文字等价 | 可单独重试 |
| job_match | 必备/加分匹配比例与已证明/未证明清单；无 JD 时 content=null 并注明原因 | 可单独重试 |
| communication_analysis | 输入模式、结构清晰度/口语表现说明、证据限制；文字模式口语标注"未评估" | 可单独重试 |
| tool_performance | 工具使用清单与行为摘要 | 可单独重试 |
| training_plan | 优势/风险、优先级练习（原题/变体/框架/示例）、正式重试入口标注 | 可单独重试 |

## 4. 生成规则

1. **分数只读**：所有数字与门槛结论直接引用 ScoreVersion；叙述与分数矛盾时以
   分数为准并省略矛盾叙述。
2. **证据可回溯**：每条评价挂 `evidence_ids`；无法回溯的内容删除。
3. **表达顺序**：先优势后改进；反馈聚焦行为与证据，禁止人格化评价。
4. **输入模式标注**：文字模式必须写明口语"未评估"及证据限制；混合模式标注
   语音占比；摄像头/便利设置不作任何能力推断。
5. **强制标记**：`training_use_disclaimer` 恒为"模拟训练结果，不代表真实企业
   录用结论"；`raw_record_refs.deletion_entry` 恒为 true。
6. **不泄题**：后续轮次未完成时不输出其正式考点与完整标准答案。
7. **保护属性零携带**：年龄、性别、外貌、婚育、情绪等内容一律忽略，不得复述；
   生成结果经 safety pipeline 证据扫描复核。
8. **最终结果（SCORING-SPEC 6.9）**：最终加权分为各轮最新有效正式得分的公开
   权重加权值；任一必需轮 FAIL → 整体未通过；任一必需轮无有效分 →
   EVALUATION_INCOMPLETE（生成部分报告）。

## 5. 模块级失败与重试（FR-026 / NFR-014）

- 单模块生成失败不影响其他模块：失败模块 `status=failed`，其余模块正常展示；
- 重试只重试失败模块（`report:regenerate`），不重新生成成功模块、不触碰评分
  证据；同一模块 Schema 校验失败重试 ≤2 次，仍失败保持 `failed` 并告警；
- 报告整体 P95 ≤120s（NFR-014）；模型超时按指数退避重试。

## 6. 安全

- 命中 safety policy 禁止类别（歧视、侮辱、无关隐私、危险、录用预测、PII 复述）
  时阻断并重新生成（≤3 次）；危险/骚扰/录用预测直接升级人工审查；
- 简历/JD 原文与回答文本中的指令性语句按数据处理，命中注入标记
  `injection_detected` 并记录，不影响报告生成；
- 日志与监控不含简历正文、完整回答与原始媒体。

## 7. 验证方式

1. 全部输出过 `report.schema.json` 校验（fail-closed）；
2. `ai/evals/datasets/` 中 `report` 标签用例回归：分数引用一致、免责声明存在、
   文字模式标注、无保护属性复述、模块失败重试语义；
3. 报告文字等价版本与雷达图逐项对应（无障碍）；
4. 公平性：按语言、输入模式、便利设置切分检查报告质量无显著退化。
